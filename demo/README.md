# FinTrace demo

Time-travel through SEC as-filed XBRL facts: pick a company, a metric, and a
knowledge cutoff — see what was actually public then, next to what a naive
live-data API returns today (the look-ahead view).

`demo.duckdb` (not committed here; uploaded to the Space separately) is a
star-company subset generated by `fintrace demo-export` from SEC EDGAR public
data. Reproduce locally: clone the main repo and run
`uv run fintrace demo-export`.
